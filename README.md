# 🚀 Web Server Using Java

A Java-based web server built from scratch to **revise and practically understand Operating Systems, Computer Networks, Multithreading, and Concurrency**.

## 🏗️ Implementations

* **Single-Threaded Web Server**
* **Multi-Threaded Web Server**
* **Thread-Pool Web Server** with a fixed pool size of **10 threads**

## 🧪 Testing

Tested using **Apache JMeter** with a generated load of up to **500K requests per minute** to observe how different threading approaches behave under heavy load.

> **Note:** 500K requests/minute is the generated test load, not 500K successfully processed requests.

## 📚 Concepts Revised

* Java Socket Programming
* TCP/IP & HTTP
* Multithreading & Concurrency
* Thread Management
* Thread Pools & ExecutorService
* Network I/O
* Operating System Fundamentals

## 🛠️ Technologies

**Java | Socket Programming | Multithreading | ExecutorService | TCP/IP | HTTP | Apache JMeter**

## 🎯 Purpose

This project helped me connect **OS and Networking theory with practical backend server implementation** and understand how different threading models handle concurrent requests.
